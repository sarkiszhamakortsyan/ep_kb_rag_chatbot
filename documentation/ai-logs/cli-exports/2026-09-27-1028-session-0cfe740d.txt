  How it behaves:
  - Summary timing: the addresses are printed only once the servers actually
    accept connections.
  - Frontend to backend: the frontend's /api forwarding follows the backend to
    its new port.

    start moves back to it.
  - Ollama port: it can now be changed. docker-compose.yml reads OLLAMA_PORT,
    default 11434.
  - Stopping: Ctrl+C stops both dev servers.
  - Plain docker compose up doesn't check ports; it uses the values in .env as
    before.
